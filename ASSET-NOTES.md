# Visual assets

20 product visuals including the hero were created with the built-in ImageGen tool and copied into this project. They illustrate generic equipment categories and do not depict confirmed stock, exact models, manufacturer assets or partnerships. The original supplied Norda logo is unchanged. The hero PNG preserves generated alpha transparency. The earlier POS visual is excluded following the user's request to omit cash registers and mobile data terminals.

## Web delivery (v3)

Original PNG files are preserved in artwork-originals/. Delivery uses content-equivalent WebP variants in dist/assets/optimized/ (1200 px and 600 px, with alpha preserved). This is an asset delivery optimisation; no new visual subjects or brand identities were introduced. The Norda logo uses a smaller WebP variant for the header. Run optimize-assets.mjs to regenerate variants.
